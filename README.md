## Files

`index.html` contains the profile copy and platform links. `styles.css` provides responsive light and dark themes. `theme.js` stores the visitor's theme preference on their device. The `assets` folder contains the CJ Signal Clips avatar and banner.

This is a static website with no build step, backend, analytics, contact form or third-party scripts. Fonts come from the visitor's device. Brand images belong to CJ Signal Clips and are included for this website.

## Local preview

Open `index.html`, or run `python -m http.server 8798 --bind 127.0.0.1` in this folder and visit `http://127.0.0.1:8798/`.

## Hosting

GitHub Pages publishes the repository root on the `main` branch. Intended custom domain: `signal.cj-chan.work`. DNS and HTTPS must be active before treating the custom domain as live.
